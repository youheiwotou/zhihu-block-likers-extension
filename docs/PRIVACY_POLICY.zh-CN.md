# 隐私政策

最后更新：2026-05-14

“知乎黑名单同步”是一个本地运行的浏览器扩展，用于从用户配置的 GitHub 公开仓库同步多个知乎黑名单列表，也可以导出自己的网页版黑名单，并在用户明确确认后按当前列表批量屏蔽用户。

## 数据处理

本扩展不会收集、出售或分享用户数据。

本扩展会读取用户填写的 GitHub 仓库、分支和目录文件路径，并通过 `raw.githubusercontent.com` 请求公开文件。同步得到的目录和列表内容会通过浏览器提供的 `chrome.storage.local` 保存在本机。

当用户在 `https://www.zhihu.com/settings/filter` 点击“采集当前知乎页”时，本扩展会临时注入导出脚本，在“用户黑名单”区域点击“编辑”，读取编辑列表中可见的知乎用户主页链接，并通过页面右侧翻页控件继续采集。导出结果会保存在本机缓存中，用户可以复制出来自行维护到 GitHub 仓库。

当用户在扩展弹窗中选择当前列表、取消试运行并勾选确认后，本扩展可以打开执行页，逐个访问列表中的知乎个人主页，并点击页面上的“屏蔽用户”和确认按钮。执行日志保留在本地执行页中。

本扩展不会向 GitHub 写入内容，不会把本地缓存、日志或设置上传给开发者，也不会在用户未确认时后台静默执行屏蔽操作。

## 权限用途

- `activeTab`：在用户点击扩展并主动导出时，临时访问当前知乎标签页。
- `scripting`：把导出脚本或个人主页屏蔽脚本注入知乎页面。
- `tabs`：打开和复用批量屏蔽用的知乎工作标签页。
- `storage`：在本地保存仓库配置、目录缓存、列表缓存、导出结果和执行任务草稿。
- `https://raw.githubusercontent.com/*`：读取用户配置的 GitHub 公开仓库文件。
- `https://www.zhihu.com/*`：导出黑名单，以及按用户确认的列表访问个人主页并执行屏蔽操作。

## 第三方服务

本扩展使用 GitHub Raw 读取公开文件。请求这些公开文件时，GitHub 可能会按照自己的服务条款和隐私政策处理网络请求相关信息，例如 IP 地址、请求时间和 User-Agent。

本扩展不会向 GitHub 写入内容，不会要求用户提供 GitHub token，也不会加载或执行远程代码。导出自己的黑名单时，知乎网页可能会因为翻页而发起自己的页面请求；扩展不硬编码这些接口，也不会把接口返回内容上传给开发者。

## 用户控制

用户可以随时清空本地缓存，也可以在浏览器扩展管理页移除本扩展。公开仓库中的黑名单内容由仓库维护者自行管理。
